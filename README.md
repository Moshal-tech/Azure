## 🌟 Project Overview

This project was undertaken as part of my **Data Technician Bootcamp – Microsoft Azure Data Fundamentals (DP-900)** training, focusing on cloud computing, data storage, database management, data ingestion and analytics using Microsoft Azure technologies.

The training provided hands-on exposure to **relational databases, non-relational data storage and analytical workloads**, exploring how different Azure services support the end-to-end data lifecycle.

Through practical labs, I explored Azure SQL Database, Azure Storage Accounts, Azure Cosmos DB and Microsoft Fabric, developing an understanding of how organisations can manage, process and analyse structured and unstructured datasets.

The project also strengthened my SQL querying skills and knowledge of how cloud technologies can support retail and sales analytics, business intelligence and data-driven decision-making.
